# rules

- If you are asked to create a new page for learning a topic, e.g. "adverbs", do the following:
	- add an entry in the "verbs numbers" menu called "adverbs"
	- under that, create a Learn page and a Test page similar to the ones in verbs and numbers
	- allow the user to make each item as learned, and track this on the "learned" page 
	- make sure that you update the global search box so it searches the new item as well, e.g. "adverbs"
